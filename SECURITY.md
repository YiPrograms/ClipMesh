# Security policy

## Supported versions

Security fixes are made against the latest released version of ClipMesh.

## Reporting a vulnerability

Please use [GitHub's private vulnerability-reporting flow](https://github.com/YiPrograms/ClipMesh/security/advisories/new). Do not include vulnerability details, credentials, server exports, clipboard contents, or other sensitive data in a public issue.

Include the affected ClipMesh version, operating system or browser version, deployment topology, reproduction steps, and expected security impact. Use synthetic clipboard content and redact device tokens, channel passwords, keys, pairing codes, server databases, and logs before attaching diagnostic material.
